What Is a Hidden State? The Residual Stream, Read and Written

A language model turns every word into a list of numbers and keeps editing that list as it reads. If you stop the model halfway and copy the list, what have you copied, and what can you do with it? This post answers with arithmetic you can do on paper, then checks it on a real model.

1 · Hook

The list in the middle

Stop a language model halfway through its work and copy out the list of numbers it holds for one word. Libraries call this list a hidden state. The list is long: GPT-2 small has 768 numbers in it Nanda 2022, § Transformer Basics, and Qwen3-1.7B-Base, a newer model, has 2,048 Notebook 02, reference run. A list of numbers is called a vector, and the number of entries in it is its dimension.

People do three things with such lists (our summary of common practice). Say you copy the list at one layer. You can then train a small classifier on it, to see whether a property of the text can be read off; compare it with the list from another model; or add a vector to it, to push the model somewhere. All three treat the list as a definite object. So what is it?

Three questions drive this post. What is the list? What can a part of the model read from it, and write into it? What happens to a probe’s score if every list is pushed by the same vector? Each answer is arithmetic you can do on paper. At the end we ask whether a concept such as “calm” is a direction in the list, and treat that as a bet, not a fact.

We check the first question on a real model in the two notebooks that come with this post. The vocabulary and the bets come from three published sources, which section 4 introduces.

2 · Guess first

Make three predictions

Commit to an answer before you read on: a wrong guess you remember is worth more than a right answer you only read. Each answer appears in the section named under its question.

1. A model is a stack of rounds of work called blocks. You stop it after block 6 and copy the list it holds for one word. What is that list?

2. A shared list already holds (2, 2). Block 3 now writes (−2, −2) into it. What can a later block read from the list?

3. A probe gives each point in a cloud a score: multiply its two coordinates by two fixed numbers and add the results. Now add the same vector to every point of the cloud. By how much does each score change?

3 · Home field

The stream is a running sum

From words to lists

A language model reads text as tokens: whole words or pieces of words. Its first step is a lookup: a table holds one list of numbers for each token, and the model copies out the list for the token it is reading Nanda 2022, § Transformer Components, Embedding. GPT-2 adds to it a learned list for the token’s position Nanda 2022, § Positional information. We call the starting list, position list included, the embedding and write it x0x_0 (the sources use “embedding” in four ways, so we keep the word for this one list).

From that start, the model keeps one working list for the token, and every attention and MLP part of the model changes it by adding to it. We call it the residual stream, or the stream. GPT-2 small has 768 numbers in it and 12 blocks Nanda 2022, § Transformer Basics. Our toy uses two, so that every list can be drawn on paper.

Add two vectors by hand

Before any diagram, do one sum on paper. A part of the model adds the vector (2, −1) to a stream that holds (1, 2). Add the first numbers, then the second numbers, and only then read on.

First numbers: 1 + 2 = 3. Second numbers: 2 + (−1) = 1. The answer is (3, 1), in whichever order you add. As a rule:

(a,b)+(c,d)=(a+c,  b+d)(a,b)+(c,d)=(a+c,\;b+d)

Read it aloud as “first plus first, second plus second”. The same rule holds for 768 numbers, if both lists have the same length.

A block writes by adding

Between the starting list and the answer, a model has a stack of blocks. Each block has two parts in a fixed order: an attention part, then an MLP part (multi-layer perceptron, a small network). We say block for the pair and sub-layer for each part, because “layer” is confusing: a transformer layer “actually contains two layers” Nanda 2022, § Transformer Basics.

Each sub-layer looks at the stream, computes a vector, and adds it to the stream. It never overwrites it: layers “write” their result to the stream “by adding a linear projection back in” Elhage 2021, § High-Level Architecture (section 5 explains “linear projection”). We call the vector a sub-layer adds its write: aka_k for the attention in block kk, fkf_k for the MLP.

Now a toy (toy numbers, ours). The embedding is x0=(1,2)x_0=(1,2). Block 1 writes a1=(2,−1)a_1=(2,-1) and then f1=(−1,1)f_1=(-1,1). Block 2 writes a2=(3,−2)a_2=(3,-2) and then f2=(−1,2)f_2=(-1,2). Add the writes one at a time, on paper first. Then tap Next to check each row; the diagram below shows the same sums.

The pattern and the formula

The stepper shows the pattern: start with the embedding and add the writes in the order they happen. With xkx_k for the stream after kk blocks:

xk=x0+(a1+f1)+(a2+f2)+⋯+(ak+fk)x_k=x_0+(a_1+f_1)+(a_2+f_2)+\dots+(a_k+f_k)

Read it aloud: “the stream after kk blocks is the embedding plus every write up to block kk.” Elhage and colleagues put it this way: “The residual stream is simply the sum of the output of all the previous layers and the original embedding.” Elhage 2021, § Communication Channel Check with the toy:

x2=(1+2−1+3−1,  2−1+1−2+2)=(4,2)x_2=(1+2-1+3-1,\;2-1+1-2+2)=(4,2)

The stepper’s last row says (4, 2) too. One everyday picture, as a picture only (ours): a bank balance is the opening balance plus every deposit and withdrawal since, and a later withdrawal can cancel an earlier deposit. The rest of the post tests how far the picture holds.

The sum is bookkeeping: it tells you what is in the stream, not what any writer meant. It is exact in the account Elhage and colleagues give, which says: “We also ignore layer normalization.” Elhage 2021, § Model Simplifications Real models add a norm (short for normalisation): a rescaling step applied to the stream before each read Nanda 2022, § Transformer Components, LayerNorm. It subtracts the average of the list’s numbers, divides by their typical distance from that average (the standard deviation), and then applies a learned scale and shift. Before that last step, a list and its double give the same result. The list (4, 2) has average 3, so it is centred as (1, −1); its standard deviation is 1; the result is (1, −1). The list (8, 4) has average 6, centred (2, −2), standard deviation 2, so the result is again (1, −1). GPT-2 uses this version Notebook 02, reference run. Two fold-outs give more: a code reading at the end of this section and a norm table in section 6.

One stream per position

Take the two-word input “red car”. The model keeps one stream for each word, at every depth: “Importantly, there is a separate residual stream for each position in the sequence.” Nanda 2022, § Transformer Basics Only attention carries information between positions Nanda 2022, § Transformer Basics, and in a decoder-only model, which predicts text from left to right, only from earlier ones Nanda 2022, § Decoder-only.

So there is no “hidden state of a sentence”; a summary of a sentence is a further step that someone must choose (ours).

Is the hidden state the stream?

The Hugging Face transformers library, a Python library that loads language models, returns the list after each block as hidden_states. None of the three sources uses the phrase “hidden state”, so we test the identity (ours). Copy the list after kk blocks. Separately, record every write inside the blocks and add them to the starting list. If the sum equals the copied list up to rounding, they are the same vector.

We ran this on GPT-2 small (12 blocks) with the sentence “The cat sat on the mat because”, in 32-bit numbers (float32, about seven digits). Subtracting neighbouring entries of the library’s list should give each block’s two writes. Over the first eleven blocks they differed by at most 6.2e−6, relative to the size of the block’s own two writes at that position. Measured against the stream instead, the same differences are about 4e−8 to 7e−7 Notebook 02, reference run. That is rounding: in the toy, whole numbers add exactly in any order, but a computer rounds after each addition, so another order rounds in other places.

So in GPT-2 small, entry kk of the library’s list, for k=0k=0 to 11, is the stream after kk blocks, up to rounding, and entry 0 is x0x_0. The last entry is the exception: the library replaces it with the model’s final output, which has been through the final norm HF output_capturing.py, lines 243–246, so “the hidden state at the last layer” is not a stream vector. We ran no trained Qwen3, Llama, Gemma or Mistral model; the fold-out at the end of this section has the full table and a warning about Gemma 3.

Term · Residual stream (also called hidden state, embedding)

The residual stream is the working list a model keeps for each word. Libraries call it a hidden state, and Elhage and colleagues note that its vectors are often called the embedding. Here embedding means only x0x_0, stream the running list, and hidden state what a library returns; by the test above they are equal for entries 0 to 11 in GPT-2 small.

Trap · where the bus picture misleads (ours)

A computer bus has one writer at a time, and each message has an address. In the stream every sub-layer adds to the same list in turn, with no addresses, and a reader sees only the sum. Elhage and colleagues say they generally think of it as “a communication channel” Elhage 2021, § Communication Channel.

Prediction 1 · answer

A running total. In GPT-2 small, the list after block kk is the embedding plus every write so far, up to rounding. The other options fail: the list holds no answer, only a sum; earlier writes stay in the sum; each word has its own list. Limit: the library’s last list is normed.

4 · Three bets

Three bets, held lightly

The lens we want to end with has three parts: concepts are directions, features connect through weights into circuits, and similar features recur across models. Olah and colleagues, writing in 2020 about an image-recognition network, called them “deliberately speculative” claims Olah 2020, § Three Speculative Claims. We treat each as a bet: an instance first, then the claim and how firmly it was held.

Bet 1 · Features are directions

Instance (toy, ours). Take six points in a plane: three calm, (3, 1), (4, 2) and (5, 3), and three urgent, (1, 3), (2, 4) and (3, 5). Neither coordinate alone separates them, but “second number minus first” does: −2 for every calm point, +2 for every urgent one. If a model stored “calm” like this, the concept would be a direction, the arrow (−1, 1). Section 6 redoes this with dot products.

The claim: “Features are the fundamental unit of neural networks. They correspond to directions.” Olah 2020, § Three Speculative Claims A feature is, for Nanda, “a property of an input to the model, or some subset of that input” Nanda 2022, § General; a concept is our word for a feature we can name. For Olah and colleagues a direction is a weighted mix of neurons in a layer Olah 2020, § Three Speculative Claims (a neuron is one small unit of a network; section 5 shows one). The stream has no neurons Nanda 2022, § Transformer Components, so for the stream a direction is a weighted mix of its coordinates (ours).

How firmly? On whether networks “consist of meaningful, understandable features”, Olah and colleagues concede: “The community is divided on whether this is true.” Olah 2020, § Claim 1: Features If concepts were directions, a concept’s strength would be a dot product.

Bet 2 · Features are connected by weights, forming circuits

Instance (ours). Part A feeds part B with weight 2, and B feeds part C with weight −1. In a linear chain, a rise of 1 in A reaches C as 2 × (−1) = −2, which the weights alone tell you. Section 5 builds a small table of weights of this kind.

The claim: “Features are connected by weights, forming circuits.” Olah 2020, § Three Speculative Claims A circuit is some features and the weighted connections between them, a subgraph of the network Olah 2020, § Three Speculative Claims (nothing to do with electricity). The step to whole behaviours is hedged: “it seems like, with sufficient effort, statements about model behavior could be broken down into statements about circuits” Olah 2020, § Interpretability as a Natural Science. Their worked circuits are three, in image-recognition networks, and testing one by editing its weights is a plan, not a result Olah 2020, § Circuit 2.

Bet 3 · The same features and circuits recur across models

Instance (ours). Turn every axis of the six-point toy by 90°. All the coordinates change, yet it is the same toy. Is the feature in the turned toy “the same” feature? Universality asks that of different models.

The claim: “Analogous features and circuits form across models and tasks.” Olah 2020, § Three Speculative Claims Their evidence is, in their words, “anecdotal”, from low-level features in vision models. They “suspect that the universality hypothesis is likely true, but further work will be needed” to understand if “the apparent universality of some low-level vision features is the exception or the rule” Olah 2020, § Claim 3: Universality. Unlike the first two claims, it “wouldn’t be completely fatal to circuits research” if false Olah 2020, § Claim 3: Universality.

Trap · three sources, three vintages

Olah and colleagues use an image-recognition network called InceptionV1, and “believe these claims hold generally” Olah 2020, § Claim 1: Features. Elhage and colleagues study attention-only transformers of two layers or fewer (they promise a forthcoming paper on larger ones, not among our sources) Elhage 2021, Introduction. Nanda’s glossary is “mostly a description of how GPT-2 works”, though the variants are “all essentially the same thing, even GPT-3, Gopher, Chinchilla and PaLM” Nanda 2022, § Transformer Basics. This is the one place where we state the scope for the whole post: none of the three says anything about Qwen3, Llama 3, Gemma 3 or Mistral AI’s models, base versus instruct models, what post-training changes inside a model, or steering (the word does not occur), and none tests concepts as directions in a language model’s stream.

Look inside: Olah’s three claims, sorted by firmness

The verbs follow the sources’ own firmness. All quotes are from the saved pages (Olah et al. 2020; Nanda 2022). The words in the claim boxes carry no hedge inside the box; the hedges sit around them.

Claim 1 · features are directions

  • Asserts: “These features can be rigorously studied and understood.” Olah 2020, § Three Speculative Claims And: “Curve detecting neurons can be found in every non-trivial vision model we’ve carefully examined.” Olah 2020, § Example 1: Curve Detectors
  • Believes: “thousands of hours of studying individual neurons have led us to believe the typical case is that neurons … are understandable” Olah 2020, § Claim 1: Features. And: “believe these claims hold generally”.
  • Concedes: on whether networks “consist of meaningful, understandable features”, “The community is divided on whether this is true.” Olah 2020, § Claim 1: Features
  • Hedges: the claims are “deliberately speculative”, and “if true, they could form the basis of a new “zoomed in” field of interpretability” Olah 2020, § Three Speculative Claims.
  • Nanda, on “features as directions”: gives an intuition (ours: an argument, not a measurement): “the main thing a model is capable of doing is linear algebra”, and concludes that it is “an extremely natural way to represent things” Nanda 2022, § Representations of Features.
  • Nanda, on the neuron version: “a decent amount of empirical evidence that this is mostly true of Inceptionv1, but this seems at best only slightly true for transformers” Nanda 2022, § Representations of Features.

Claim 2 · circuits

  • Asserts: “Features are connected by weights, forming circuits.” “These circuits can also be rigorously studied and understood.” “You can literally read meaningful algorithms off of the weights.” (They put this after understanding the features a circuit connects.) Olah 2020, § Claim 2: Circuits “In fact, for small enough circuits, statements about their behavior become questions of mathematical reasoning.” Olah 2020, § Interpretability as a Natural Science
  • Supposes: “it seems like, with sufficient effort, statements about model behavior could be broken down into statements about circuits”, then “perhaps circuits could act as a kind of epistemic foundation for interpretability” Olah 2020, § Interpretability as a Natural Science.
  • Proposes and plans: “if you understand a circuit, you should be able to predict what will change if you edit the weights” Olah 2020, § Interpretability as a Natural Science; the test itself is future work Olah 2020, § Circuit 2.
  • Concedes, of the curve circuit: “although there are many smaller weights we don’t understand the role of” Olah 2020, § Claim 1, Argument 5.

Claim 3 · universality

  • Asserts (the claim box): “Analogous features and circuits form across models and tasks.”
  • Concedes: “the only evidence we can offer today is anecdotal”. Suspects: “that the universality hypothesis is likely true, but further work will be needed” to understand if “the apparent universality of some low-level vision features is the exception or the rule”. Imagines: “If it was true in the strongest sense, one could imagine a kind of “periodic table of visual features”” Olah 2020, § Claim 3: Universality.

Nanda’s flat statements

Nanda defines “features as directions” as a hypothesis, but elsewhere writes without a hedge: “Features are the fundamental building block of models” Nanda 2022, § General, and “‘What token is this’ and ‘what position is this in’ are represented as separate directions in the residual stream” Nanda 2022, § Induction Circuits. The glossary gives no evidence next to either line.

5 · Reads and writes

Reads and writes

A read is a weighted look

Every part of the model also reads the stream before it writes. Take one small reader inside block 2’s MLP: a neuron (one small unit of the MLP) with an input vector r=(1,2)r=(1,2). It looks at the stream after attention 2, which holds (5,0)(5,0). What single number does it get?

Multiply matching numbers and add: 1⋅5+2⋅0=51\cdot5+2\cdot0=5. The vector rr says how much to care about each place. With r=(1,0)r=(1,0) the reader would take only the first number; with r=(0,1)r=(0,1), only the second. As a formula:

r⋅x=r1x1+r2x2r\cdot x=r_1x_1+r_2x_2

Read it aloud as “first times first plus second times second”. This is the dot product, and the rule is the same for 768 numbers.

Nanda says: “Reading is a projection, the residual stream is dotted with each input vector of the relevant matrix.” Nanda 2022, § Mathematical Framework, Composition Elhage and colleagues say that layers read “by performing a linear projection” Elhage 2021, § High-Level Architecture. In our terms (ours), a linear projection is a set of dot products, one for each number the reader produces.

We call the number r⋅xr\cdot x a score. (“Projection” also names the point on a line closest to xx; we use the number.)

Who hears whom

The stream is a sum, and the dot product of a sum is the sum of the dot products. So a read splits into one share for each writer. The stream after attention 2 is x0+a1+f1+a2=(5,0)x_0+a_1+f_1+a_2=(5,0), so

r⋅x=r⋅x0+r⋅a1+r⋅f1+r⋅a2r\cdot x=r\cdot x_0+r\cdot a_1+r\cdot f_1+r\cdot a_2

With r=(1,2)r=(1,2) the shares are 1⋅1+2⋅2=51\cdot1+2\cdot2=5 for the embedding, 1⋅2+2⋅(−1)=01\cdot2+2\cdot(-1)=0 for attention 1, 1⋅(−1)+2⋅1=11\cdot(-1)+2\cdot1=1 for MLP 1, and 1⋅3+2⋅(−2)=−11\cdot3+2\cdot(-2)=-1 for attention 2. They add up to 5+0+1−1=55+0+1-1=5, the same as the direct read r⋅(5,0)=5r\cdot(5,0)=5. Now change rr in the widget. This reader cannot hear attention 1; can you find a reader that cannot hear the embedding (1,2)(1,2)?

Answer

r=(2,−1)r=(2,-1) or r=(−2,1)r=(-2,1): 2⋅1+(−1)⋅2=02\cdot1+(-1)\cdot2=0.

Two things to notice. First, attention 1 wrote (2,−1)(2,-1) and it sits in the stream, yet this reader hears none of it. Two vectors whose dot product is zero are called orthogonal: they are at right angles. Second, reading is not the opposite of writing: “Note that these operations are not opposites!” Nanda 2022, § Mathematical Framework, Composition A reader along rr does not get back what a writer put along rr, unless the other writers are orthogonal to rr.

It works on a real stream too. In notebook 02, GPT-2 small’s stream at the last position after 6 blocks, read by a random unit vector (seed 0), gives 7.211561; the sum of its 13 shares (the embedding and the 12 writes of 6 blocks) gives 7.211561 as well, a difference of 0.0 in this run Notebook 02, reference run. A real model also puts a norm in front of every read Nanda 2022, § Transformer Components, LayerNorm; the fold-out at the end of section 6 shows what that does.

A write adds, and writes can cancel

Now the other direction. MLP 2 writes f2=(−1,2)f_2=(-1,2) into a stream that holds (5,0)(5,0). Nothing is replaced: (5,0)+(−1,2)=(4,2)(5,0)+(-1,2)=(4,2). The second numbers of a2a_2 and f2f_2 are −2-2 and +2+2, so the −2-2 is no longer visible; the first numbers, 33 and −1-1, leave a net +2+2.

The extreme case is the second guess-first question. The list holds (2,2)(2,2) and block 3 writes (−2,−2)(-2,-2): the sum is (0,0)(0,0), and every reader gets 0. Does this happen in real models? Elhage and colleagues write of hints: “we’ve seen hints that some MLP neurons and attention heads may perform a kind of "memory management" role” Elhage 2021, § Residual Stream Bandwidth. Our toy shows that cancellation is possible by arithmetic, not that models do it.

Prediction 2 · answer

Only the sum, (0, 0). A write adds; it does not replace, and it is not kept as a separate item. Whether real models cancel writes is, in the sources, a hint worded with “may”.

Cashing in bet 2, and what “linear” covers

The widget’s table gives one number for every pair of writer and reader. That is the shape of a weighted connection in a circuit, so it is “like an edge weight” (ours), though not one of Olah’s edges, which join features in adjacent layers Olah 2020, Glossary. Whether real behaviours are circuits stays a bet.

The word linear has three uses here, and only two are settled: (i) the stream is a sum of writes (the five vectors of section 3 add to (4, 2)); (ii) a read is linear in the stream, so it splits over the writers (the four shares above); (iii) “a concept can be read linearly” is a bet (section 6). The norm’s “divide by the standard deviation” step is non-linear Nanda 2022, § Transformer Components, LayerNorm.

Probe and push: directions in a toy cloud

A cloud of streams

Now we need many streams at once. Take six streams at one depth, for six short prompts (toy numbers, ours): three labelled “calm” and three “urgent”. Can one number per point tell the groups apart?

groupthe three points
calm(3, 1), (4, 2), (5, 3)
urgent(1, 3), (2, 4), (3, 5)

Try the coordinates first. The first numbers are 3, 4, 5 for calm and 1, 2, 3 for urgent: the groups overlap at 3. The second numbers overlap at 3 too. So no single coordinate separates them.

A score along a direction

Now turn a reading arrow instead of using the axes. A direction here is an arrow from the origin with length 1 (our convention). The length of (a,b)(a,b) is a2+b2\sqrt{a^2+b^2}, by Pythagoras. The arrow (−1,1)(-1,1) has length 2=1.414\sqrt2=1.414; dividing both numbers by it gives u=(−0.707, 0.707)u=(-0.707,\,0.707), “second minus first, scaled”.

Why length 1? Drop a perpendicular from a point onto the arrow’s line (the widget draws these as dotted lines). For an arrow of length 1, the score s=u⋅xs=u\cdot x is how far along the arrow the foot of that perpendicular lies, positive one way and negative the other (textbook geometry, ours). So scores from different arrows can be compared. Check: take u=(0.6,0.8)u=(0.6,0.8), which has length 1, and x=(5,0)x=(5,0). The score is 3, the foot is 3u=(1.8,2.4)3u=(1.8,2.4), and x−foot=(3.2,−2.4)x-\text{foot}=(3.2,-2.4) has dot product 1.92−1.92=01.92-1.92=0 with uu: the dotted line is at right angles.

For the calm point (4,2)(4,2): −0.707⋅4+0.707⋅2=−1.414-0.707\cdot4+0.707\cdot2=-1.414. Every calm point scores −1.414-1.414 and every urgent point +1.414+1.414, so one number now separates the groups. The gap is the margin: the lowest urgent score minus the highest calm score, here 1.414−(−1.414)=2.8281.414-(-1.414)=2.828. A positive margin means the groups are separated, with urgent above calm; zero means they touch; a negative margin means they overlap, or calm lies above urgent.

Now turn the arrow yourself. Drag the dark arrow in the widget and find the angle with the largest margin; the table below it lists some angles.

The widget turns uu by an angle φ\varphi, measured from the first axis. A unit arrow at that angle is u=(cos⁡φ,sin⁡φ)u=(\cos\varphi,\sin\varphi): cos⁡φ\cos\varphi and sin⁡φ\sin\varphi are the horizontal and vertical position of the point at angle φ\varphi on a circle of radius 1. So

s=u⋅x=x1cos⁡φ+x2sin⁡φs=u\cdot x=x_1\cos\varphi+x_2\sin\varphi

Steering is a translation

Now push. Add the same vector vv to every point; this is what people call steering. Take v=(−2,2)v=(-2,2). Every calm point lands where an urgent point started, and the urgent points move too. The dot product of a sum is the sum of the dot products, so every score moves by the same amount, u⋅v=−0.707⋅(−2)+0.707⋅2=2.828u\cdot v=-0.707\cdot(-2)+0.707\cdot2=2.828. Calm scores go from −1.414-1.414 to 1.4141.414, and urgent scores from 1.4141.414 to 4.2434.243. As a formula:

s(x+v)=s(x)+u⋅vs(x+v)=s(x)+u\cdot v

What is a push good for in the toy? A push along uu shifts every score the probe reads and leaves the margin at 2.828, because both groups travel together. A push at right angles to uu, such as v=(2,2)v=(2,2), has u⋅v=0u\cdot v=0: every point moves and no score moves. Try the buttons “push along” and “push sideways”.

A push is a translation: every point slides by the same vector. It is not linear, because a linear map sends the zero vector to zero, and adding vv sends it to vv. A linear step plus a constant is called affine.

What this does not say. Nothing here says that adding a vector changes behaviour as intended. On a real stream only the arithmetic holds: in notebook 02, for GPT-2 small’s last position after 6 blocks and a random unit direction uu, u⋅(h+αu)−u⋅h−αu\cdot(h+\alpha u)-u\cdot h-\alpha was 0 for α=0.5,1,2,5\alpha=0.5,1,2,5 and −3-3 Notebook 02, reference run.

Prediction 3 · answer

By the same amount, whichever point it is. Each score moves by u⋅vu\cdot v, whatever the point. It is the same for near and far points, and for points on or off the probe’s line.

Turn everything

One more property, about coordinates. Turn the whole toy by 90°: each (x,y)(x,y) becomes (−y,x)(-y,x), and so does rr. Take the read of section 5, r=(1,2)r=(1,2) on the stream (5,0)(5,0): the stream becomes (0,5)(0,5) and rr becomes (−2,1)(-2,1), and the read is still (−2,1)⋅(0,5)=5(-2,1)\cdot(0,5)=5. Every coordinate changed, but lengths and angles did not, so no dot product changed: the four shares of section 5 are 5, 0, 1 and −1 before and after. In symbols, for a rotation RR:

(Rr)⋅(Rx)=r⋅x(Rr)\cdot(Rx)=r\cdot x

Check for 90°: Rr=(−r2,r1)Rr=(-r_2,r_1) and Rx=(−x2,x1)Rx=(-x_2,x_1), so (Rr)⋅(Rx)=(−r2)(−x2)+r1x1=r⋅x(Rr)\cdot(Rx)=(-r_2)(-x_2)+r_1x_1=r\cdot x. This is textbook arithmetic (ours). Nanda gives the principle: “Operations like addition, matrix multiplication, dot products, etc are unchanged under any change of basis.” Nanda 2022, § Representations of Features The slider shows the shares staying put at every angle, while the first coordinate of the stream moves.

A basis is the set of axes we write coordinates in. A basis is privileged if its single coordinates, such as “dimension 17”, mean something on their own. Nanda: “A privileged basis is a meaningful basis for a vector space.” Nanda 2022, § Representations of Features Elhage and colleagues assert, for their idealised linear stream, that it “doesn't have a "privileged basis"” Elhage 2021, § Communication Channel.

The neurons of an MLP are different: after the activation function (a curve applied to each number on its own; the ReLU turns every negative number into 0), “in the standard basis a ReLU acts on each coordinate independently” Nanda 2022, § Representations of Features. So do not read “dimension 17” as a feature on that ground alone; compare the vectors of one model by dot products among them. Nanda adds a caveat: “the standard basis is always slightly privileged” (floating-point numbers and the Adam training method favour it), so he thinks of it as a spectrum, not a switch Nanda 2022, § Representations of Features.

Cashing in bet 3. Let “model B” be model A with everything rotated. Every coordinate differs, but every dot product in B equals the one in A. A comparison that used coordinates would call B different, so a fair comparison must not use them (ours). That is a reason, not a result about real models.

Look inside: a norm before every read

Section 3 defined the norm in two lines. Nanda says a normalisation step is used “whenever the residual stream is input into a layer (ie before the attention, MLP and unembedding layers)”. It has four steps: subtract the mean, divide by the standard deviation, scale, translate. Of these, “the “divide by the standard deviation” step is non-linear (but the other 3 are linear)” Nanda 2022, § Transformer Components, LayerNorm. For their idealised model, Elhage and colleagues write that “up to a constant scalar, the layer normalization is a constant affine transformation” Elhage 2021, § Communication Channel.

Look inside: the logit lens is one more read

The last step of a model, the unembedding, turns the final stream into one score for each possible next token (these scores are called logits). Each score is a dot product with one row of a table. The logit lens applies that last step to earlier streams. As Nanda describes it (the original post is not among our sources), it normally applies “the final layer norm, and unembed, and log_softmax”, where log_softmax turns the scores into log-probabilities. His summary of the finding: “often, the model has become confident in the correct next token before the final layer, and each layer incrementally improves and refines that confidence” Nanda 2022, § Logit lens. He reads this as “evidence for thinking about transformers as having the central object of the residual stream, that each layer incrementally updates”.

A toy (ours; invented rows; no norm). Let three tokens have unembedding rows at 0°, 120° and 240°. Applied to the running stream of section 3, they give these scores:

7 · Synthesis

Short answer

Short answer (our reading, not a finding)

(a) What is the list? In GPT-2 small, the list a library returns after kk blocks, for k=0k=0 to 11, is the embedding (the token’s table row plus its position list) plus every earlier write, at one position, up to rounding. The library’s last entry has been through the final norm, so it is the exception. For a trained Qwen3, Llama, Gemma or Mistral model we have no measurement; in code and tiny random models, Gemma 3 norms each sub-layer’s output before adding it. What would change our mind: an additivity error above rounding with the hooks placed correctly.

(b) What can you do with it? A part reads the list by dot products, which split into one share per writer (a writer at right angles to the reader goes unheard), and writes by adding, so writes can cancel. A probe is a dot product. Steering is a translation: it moves every score by u⋅vu\cdot v, so a push along the probe shifts the scores and leaves the margin alone, while a push at right angles changes none. To compare two models, use each model’s own dot products, not coordinates (ours; Elhage and colleagues assert that an idealised stream has no privileged basis). All this is exact arithmetic. What a score means, or whether a push changes behaviour, the algebra does not say.

(c) How firm is the lens? All three of Olah and colleagues’ claims are “deliberately speculative”, and their evidence comes from image-recognition networks, mostly one called InceptionV1. For the trained language models people use now, the three sources give no test: Elhage and colleagues report circuits only in attention-only transformers of two layers or fewer, and none of the three tests concepts as directions or behaviours such as refusal or trust. We hold all three claims as bets. The toys say what each bet would mean, not whether it is true.

8 · Lens 1

Lens 1 · Linear algebra

same-math Stream = a sum of vectors. Write = vector addition. Read = dot product. Steering = translation. No privileged basis = rotation leaves dot products unchanged. Only this bookkeeping is the same mathematics; the sub-layers themselves are not linear.

Seeing is not doing (ours). A probe observes: it reads the stream. Steering intervenes: it writes into it. A high probe score shows that information is present along a direction, not that later parts of the model use it. Testing use takes further tests, which this post does not run. Nanda’s glossary lists interventions such as ablation (deleting a part) and activation patching (swapping in the activation from another input) Nanda 2022, § Mechanistic Interpretability Techniques, and a gradient-based test, TCAV, which compares a probe-like direction with the direction that, intuitively, would most raise an output (its example is a zebra in an image) Nanda 2022, § Non-MI Techniques, TCAV. He cautions that zero ablation “is arguably unprincipled, because the model may be using that part as a bias term” Nanda 2022, § Ablation.

One more limit. Cosine similarity (the dot product divided by the two lengths) is not additive. In notebook 02, with v=3uv=3u, the cosine of h+vh+v with uu was 0.1318, while the cosine of hh with uu plus the cosine of vv with uu was 1.0935 Notebook 02, reference run. A dot product splits over writers; a cosine does not.

Connection to your research (3C). Computation. Probing, similarity analysis and steering are three statements about one vector. This lens fixes what the vector is and which operations on it are exact.

Adds: exactness for the bookkeeping, and three habits: check the sum, split a read over its writers, distrust a coordinate. Does not explain: why concepts would be directions at all (bet 1), anything nonlinear (the MLP’s curve, attention weights, the norm’s division), and whether a probe’s direction is used by the model. By Nanda’s caveat (“always slightly privileged”), “no privileged basis” is a habit, not a law (ours).

9 · Lens 2

Lens 2 · Information theory

structural analogy Many writers add into one shared vector, and a reader sees only the sum, as in MacKay’s binary multiple access channel, whose output is the sum of two inputs (the link is ours). metaphor “Bus” and “bandwidth”. No theorem or number transfers.

This lens asks a question and does not answer it. A stream has dd numbers, and a model may have more things to say than dd. How many separate messages can one reader recover, if some interference is tolerated?

Elhage and colleagues call the stream’s dimensions “something like "memory" or "bandwidth"”: the words count dimensions Elhage 2021, § Residual Stream Bandwidth. Nanda defines superposition as the case when a model “represents more than n features in an n dimensional activation space”, and argues that with 50,000 tokens and 768 dimensions “there almost has to be more features than dimensions” Nanda 2022, § Toy Model of Superposition. “Almost” matters: it is an argument, not a measurement. Here writes add; superposition means only the model-side sense.

MacKay sets an exercise on a channel “with two sets of inputs and one output”. In the simple case the output is “equal to the arithmetic sum of the two inputs, that’s 0, 1 or 2”, with no noise. If the output is 1, “it could be that the input state was (0, 1) or (1, 0)”: the receiver cannot tell who sent the 1 MacKay 2003, Exercise 15.18, p. 237. We use no result from the exercise.

A toy (ours). The stream has two numbers. Three features are written along directions at 0°, 120° and 240°: g1=(1,0)g_1=(1,0), g2=(−0.5, 0.866)g_2=(-0.5,\,0.866), g3=(−0.5, −0.866)g_3=(-0.5,\,-0.866). Feature jj has strength cjc_j, and the stream is c1g1+c2g2+c3g3c_1g_1+c_2g_2+c_3g_3. Three readers read along g1g_1, g2g_2, g3g_3. This is superposition: three features in two dimensions. Write only feature 1: the stream is (1,0)(1,0) and the readers hear 1.000, −0.500 and −0.500, so readers 2 and 3 hear something nobody wrote for them. Write all three: the stream is (0,0)(0,0), and the readers hear 0, 0 and 0, as if nothing were written. The pattern: gj⋅gj=1g_j\cdot g_j=1 and gj⋅gk=−12g_j\cdot g_k=-\tfrac12 for j≠kj\neq k (the cosine of 120°), so

readj=cj−12 (the other two strengths, added)\text{read}_j=c_j-\tfrac12\,(\text{the other two strengths, added})

Check: for strengths (1,0,0)(1,0,0), reader 2 hears 0−12(1+0)=−0.50-\tfrac12(1+0)=-0.5. Besides all three at 1 and all three at 0, find a setting that looks exactly like silence.

Answer

Strengths (0.5,0.5,0.5)(0.5,0.5,0.5): each reader hears 0.5−12(0.5+0.5)=00.5-\tfrac12(0.5+0.5)=0.

Where the analogy breaks (ours). MacKay’s users “cannot hear the output of the channel”, while later parts of a transformer read the stream before they write. The sources give no rate, capacity or interference bound for the stream, so we do not claim that it is a multiple-access channel.

Connection to your research (3C). Computation. If features share a stream, one probe direction may pick up several at once: Nanda writes, as an intuition, of “other features with non-zero dot product with that direction” Nanda 2022, § Toy Model of Superposition. So any claim that a probe isolates a concept should say what else lies on the same line.

Across the two lenses (ours). Linear algebra tells us what is exact when many writers share one list: sums split, dot products split, a rotation changes nothing. It cannot say how many messages the list can carry. Information theory asks exactly that, but offers a question, not a number.

Adds: the question of limits (dd dimensions, many messages, interference when directions are not orthogonal) and a case, all three on, that looks like silence. Does not explain: how much a real model packs in, or whether any rate or capacity result transfers. Ours: the link to MacKay’s channel is a structural analogy about shape (several writers, one sum), nothing more.
