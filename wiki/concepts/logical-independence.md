# logical-independence

## Definitions in the sources

### information-theory

- [[jaynes-2003-probability/ch08-sufficiency]] (pp. 258–260): given $H,I$, knowing one data set tells nothing about the other; distinct from causal independence, which is not enough for the $\sqrt N$ rule or for combining conclusions [new]
- [[jaynes-2003-probability/ch18-p]] (p. 585): P(A|BC) = P(A|C), as opposed to causal independence; needed for limit theorems [new]
