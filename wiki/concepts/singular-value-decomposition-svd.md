# singular-value-decomposition-svd

## Canon spine entry

- **singular value decomposition (SVD)** (linear-algebra): A = UΣVᵀ; every matrix is rotate, then scale, then rotate (UG)

## Definitions in the sources

### linear-algebra

- [[deisenroth-2020-mml/ch04-matrix-p2]] (p. 119): $A=U\Sigma V^\top$ for any real $m\times n$ matrix, with $U,V$ orthogonal and $\Sigma$ diagonal, non-negative [as `singular value decomposition (SVD)`]
- [[deisenroth-2020-mml/ch10-dimensionality]] (p. 333): $X=U\Sigma V^\top$; columns of $U$ are principal directions, $\lambda_d=\sigma_d^2/N$ [as `singular value decomposition (SVD)`]
- [[strang-2023-introduction/app1-ranks]] (p. 402): A = UΣVᵀ as a sum of r rank-one matrices [as `singular value decomposition (SVD)`]
- [[strang-2023-introduction/ch05-determinants]] (p. 213): E = UΣVᵀ; |det E| = |det Σ| [as `singular value decomposition (SVD)`]
- [[strang-2023-introduction/ch08-linear]] (p. 323): U⁻¹AV = Σ, with separate orthonormal input and output bases
