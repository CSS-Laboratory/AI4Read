# linear-map-transformation

## Canon spine entry

- **linear map / transformation** (linear-algebra): a function that preserves addition and scaling; grid lines stay parallel and evenly spaced (HS)

## Definitions in the sources

### linear-algebra

- [[axler-2024-ladr/ch03-linear-p1]] (p. 52): function $T:V\to W$ with additivity and homogeneity; Axler writes $Tv$ and calls $\mathcal L(V,W)$ the set of them [as `linear map / transformation`]
- [[boyd-2018-vmls/ch02-linear]] (pp. 30–31): here a scalar-valued function satisfying superposition (2.2), equivalently homogeneity plus additivity
- [[boyd-2018-vmls/ch07-matrix]] (p. 129): scaling, dilation, rotation, reflection and projection written as $y=Ax$ [as `linear map / transformation`]
- [[boyd-2018-vmls/ch08-linear]] (pp. 147–148): a function satisfying superposition (8.1); always of the form $x\mapsto Ax$
- [[strang-2023-introduction/ch08-linear]] (p. 309): a rule T with T(cv + dw) = cT(v) + dT(w); here V and W may be matrix or function spaces
