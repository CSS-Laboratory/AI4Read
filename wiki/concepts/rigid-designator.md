# rigid-designator

## Canon spine entry

- **rigid designator** (analytic-philosophy): a term that picks out the same object in every possible world in which it exists (grad)

## Definitions in the sources

### analytic-philosophy

- [[kripke-1980-naming/ch01-lecture-p1]]: the relevant passage is the contrast between "Nixon" and "the winner" at p. 41 [as `rigid designator`]
- [[kripke-1980-naming/ch01-lecture-p2]] (p. 49): designates the same object in every world where it exists (pp. 48–49); names are claimed to be rigid, *the President in 1970* is not [as `rigid designator`]
- [[kripke-1980-naming/ch02-lecture]] (pp. 75, 77–78): a term denoting the same thing in every possible world, as used in our language, even where the thing does not exist; this differs from the canon's "in every possible world in which it exists" [as `rigid designator`]
- [[kripke-1980-naming/ch03-lecture-p1]] (p. 107): a name used to refer to the same object even in counterfactual situations (p. 107); the footnote on p. 114 glosses 'B', the name of a table, as a name (rigid designator). [as `rigid designator`]
- [[kripke-1980-naming/ch03-lecture-p2]] (pp. 135–136, 148–149): a term denoting the same object in every possible world; Kripke applies it to 'heat', 'gold', 'pain', 'C-fibers' [as `rigid designator`]
- [[kripke-1980-naming/front-preface]] (pp. 3, 6, 9–10): in this preface, rigidity is stated as a rule about truth conditions: there is a single individual and a single property such that, at every counterfactual situation, the proposition's truth condition is that individual's having the property there; if 'a' and 'b' are rigid designators, a true 'a = b' is necessary [as `rigid designator`]
- [[lycan-2019-language/ch04-proper]] (p. 47): a term denoting the same item in every world where that item exists; Kripke's test is the frame *N might not have been N*
- [[lycan-2019-language/ch10-truth]] (p. 131): constant intension; a flaccid designator (new) varies across worlds [as `rigid designator`]
- [[putnam-1975-meaning/main]] (p. 149): Putnam extends Kripke's notion to substance names such as "water" [as `rigid designator`]
