# prefix-code-kraft-inequality

## Canon spine entry

- **prefix code & Kraft inequality** (information-theory): instantaneously decodable codes exist iff Σ 2^{−ℓ_i} ≤ 1; code lengths and probabilities are interchangeable (UG)

## Definitions in the sources

### information-theory

- [[cover-2006-elements/ch05-data-p1]] (pp. 81–83): prefix codes (no codeword is a prefix of another) exist for lengths $l_i$ iff $\sum D^{-l_i}\le1$
- [[cover-2006-elements/ch05-data-p2]] (pp. 102, 108, 117): prefix-freeness read as disjoint intervals; $\sum2^{-l}\le1$ used in all proofs
- [[mackay-2003-information/ch42-hopfield]] (p. 521): the conserved weight $2^{-l}$ in the southeast puzzle
- [[polyanskiy-2025-information/ch12-variable]] (p. 208): prefix codes exist for lengths with $\sum2^{-l_a}\le1$, and uniquely decodable codes obey it [as `prefix code & Kraft inequality`]
