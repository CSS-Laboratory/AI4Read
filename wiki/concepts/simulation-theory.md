# simulation-theory

## Canon spine entry

- **simulation theory** (theory-of-mind): ToM works by running one's own cognitive machinery offline on pretend inputs (UG)

## Definitions in the sources

### theory-of-mind

- [[apperly-2011-mindreaders/ch01-introduction]] (p. 5): mindreading may use one's own mind to model others' minds, without a fully specified theory
- [[apperly-2011-mindreaders/ch04-evidence]] (p. 85): mentioned only in note 11: the mPFC similarity findings do not, in Apperly's view, discriminate them
- [[apperly-2011-mindreaders/ch07-elaborating]] (p. 178): mindreading by running one's own judgement systems on the target's information. Apperly's account emphasises high-level mindreading as counterfactual or imaginative reasoning, which might comfort simulation theorists
- [[dennett-1987-intentional-stance/ch04-making]] (pp. 100–101): Stich's idea that we use ourselves as "analog computers"; Dennett argues it still needs theory-like knowledge (pp. 100–101) (canon link; Dennett writes "something like simulation" and does not use the label "simulation theory" here) [as `simulation theory`]
- [[heyes-2014-cultural-evolution/main]] (p. 4): treated as complementary to theory-theory, more relevant to implicit low-level mind reading [as `simulation theory`]
