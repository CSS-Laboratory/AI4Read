# MacKay, D. J. C. (2003). *Information Theory, Inference, and Learning Algorithms*. Cambridge University Press. ISBN 9780521642989.

## In one paragraph
MacKay treats information theory, Bayesian inference and machine learning as one subject. The book starts with entropy and compression, then proves Shannon's result that a noisy channel can carry data with arbitrarily small error at any rate below its capacity. Practical error-correcting codes follow, mostly sparse-graph codes decoded by message passing. The same probability tools then turn to inference. Models are compared by their evidence, which gives an Occam's razor. Hard posteriors are approximated by Monte Carlo sampling or by variational methods. Neural networks, Hopfield networks and Gaussian processes are read as inference problems. It matters because compressing data, decoding a message and learning from data become the same task: working backwards from observations with probability. The book teaches through puzzles and exercises.

## The path through the work
- [[mackay-2003-information/ch01-introduction]] — Adding structured redundancy lets us correct errors from a noisy channel, and Shannon showed that arbitrarily small error is possible at a non-zero rate, up to the channel capacity C.
- [[mackay-2003-information/ch02-probability]] — Probability rules (product, sum, Bayes) let us both predict data from a model and infer a model from data, and the same chapter defines entropy and relative entropy, whose key property (Gibbs' inequality) follows from convexity.
- [[mackay-2003-information/ch03-more]] — Bayes' theorem gives one complete answer to an inference problem: the posterior, built from explicit assumptions and the likelihood of the data actually observed; the same machinery handles prediction and model comparison.
- [[mackay-2003-information/ch04-source]] — For a long string of N independent, identically distributed symbols (N large) from a source with entropy H, the number of bits needed to describe them with any fixed error probability δ (0 < δ < 1) is close to NH, because almost all probability lies in a "typical set" of about 2^{NH} strings.
- [[mackay-2003-information/ch05-symbol]] — A lossless code that gives each symbol its own binary codeword must obey a length budget (the Kraft inequality), so its expected length cannot be below the entropy H(X). A prefix code with expected length below H(X)+1 exists, and Huffman's algorithm finds an optimal one.
- [[mackay-2003-information/ch06-stream]] — Arithmetic coding, a stream code, can compress a long string to within about two bits of its ideal length by pairing a predictive probability model with an interval-based coder, while Lempel–Ziv coding uses no explicit model and, for many real sources, reaches the entropy only in the limit of enormous data.
- [[mackay-2003-information/ch07-codes]] — Every complete code for integers is optimal for some implicit prior over n, so choosing a code means choosing a prior (or, alternatively, a universal code that does reasonably well across a class of priors).
- [[mackay-2003-information/ch08-dependent]] — Joint, conditional and mutual entropy for dependent variables obey simple rules (the chain rule, and I ≥ 0), and data processing cannot increase the average information about the source.
- [[mackay-2003-information/ch09-communication]] — The largest mutual information between a noisy channel's input and output, its capacity C, is proposed as the measure of what the channel can carry; the chapter states (proof in Chapter 10) that for any rate below C, communication with arbitrarily small error probability is possible.
- [[mackay-2003-information/ch10-noisy]] — Over any discrete memoryless channel (each output depends only on the current input), reliable communication is possible at every rate below the capacity C = max I(X;Y), and Shannon proves this by showing that a randomly chosen code is good on average, so a good code must exist.
- [[mackay-2003-information/ch11-error]] — A Gaussian channel with an average-power limit has capacity C = ½log(1+v/σ²), but explicit practical codes as good as Shannon promised are still unknown: random codes need exponential resources, and decoding is hard even for simply defined linear codes.
- [[mackay-2003-information/ch12-hash]] — A hash function is a fixed pseudo-random code from N bits down to M bits that turns slow search into one table look-up, and the size M needed depends on whether you fear accidental collisions, a forger (about 2^M trials) or a cheating author (about 2^{M/2}).
- [[mackay-2003-information/ch13-binary]] — Maximizing the distance between codewords (sphere packing) is only loosely related to Shannon's goal of reliable communication: good codes must decode far beyond half their minimum distance.
- [[mackay-2003-information/ch14-very]] — Averaging over random parity-check matrices, one union-bound calculation over the typical set of noise vectors shows that, for the binary symmetric channel, linear codes exist at every rate below 1−H(X) (with H(X) the noise entropy per bit), and that, for binary sources, linear compression works at every rate above H(X).
- [[mackay-2003-information/ch15-further]] — This chapter is a set of problems that moves from refresher exercises on coding and channels to multi-user settings (correlated sources, multiple access, broadcast, two-way channels), where clever coding can beat simple baselines such as time-sharing (taking turns).
- [[mackay-2003-information/ch16-message]] — A global quantity that splits into separately computable parts can be computed by simple local messages passed between neighbouring nodes, without listing all the possibilities.
- [[mackay-2003-information/ch17-communication]] — If some strings are forbidden, the capacity of the channel is log₂λ₁, where λ₁ is the principal eigenvalue of the matrix that records which state-to-state moves are allowed.
- [[mackay-2003-information/ch18-crosswords]] — Information content, log evidence and weight of evidence are all logarithms of probabilities and share units; MacKay also uses crossword counts to bound the redundancy of language, and weight of evidence to score matches in Turing's Enigma codebreaking.
- [[mackay-2003-information/ch19-have]] — In a simple additive-fitness model, a sexual population acquires information from natural selection of order √G times faster than an asexual one, and tolerates a mutation rate of order √G times higher (G = genome size in bits).
- [[mackay-2003-information/ch20-example]] — K-means groups data by hard assignment to the nearest mean; softening the assignment with a stiffness parameter β may fix some of its faults but is not going to fix all of them, which leads the author to a mixture-density-modelling view of clustering.
- [[mackay-2003-information/ch21-exact]] — Brute-force inference lists every hypothesis, computes its posterior probability and marginalizes. It is exact, but the cost grows exponentially with the number of parameters.
- [[mackay-2003-information/ch22-maximum]] — Fitting a mixture of Gaussians by maximum likelihood gives the soft K-means clustering algorithm, but maximum likelihood is not a satisfactory general method (it can have likelihood spikes and unrepresentative maxima), and maximum a posteriori (MAP) often shares these problems and also depends on the parametrization.
- [[mackay-2003-information/ch23-useful]] — A short catalogue of the distributions that recur in Bayesian modelling, grouped by the kind of variable they describe, with the advice to distrust the Gaussian's light tails and to choose a good basis (log, logit, softmax).
- [[mackay-2003-information/ch24-exact]] — Integrating out a nuisance parameter (here the Gaussian mean μ) exactly gives the Bayesian answer for σ, and it explains why the divisor is N−1 rather than N.
- [[mackay-2003-information/ch25-exact]] — For a linear code drawn as a trellis, message passing can find the most probable codeword (min–sum, with work equal to the number of edges) and each bit's exact posterior (sum–product) without listing all codewords; how much is saved depends on the code.
- [[mackay-2003-information/ch26-exact]] — When a function is a product of factors and its factor graph is tree-like, passing local messages along the edges computes every marginal, and the normalizing constant, exactly and efficiently.
- [[mackay-2003-information/ch28-model]] — Bayesian inference ranks models by their evidence P(D | H), which automatically penalizes needless complexity through an "Occam factor", and Laplace's Gaussian approximation gives a way to approximate that evidence.
- [[mackay-2003-information/ch29-monte]] — When a high-dimensional density can only be evaluated up to a constant, importance and rejection sampling are expected to degrade exponentially with dimension, so one uses Markov chain methods (Metropolis, Gibbs, slice), which scale well with dimension but move by slow random walks.
- [[mackay-2003-information/ch30-efficient]] — Metropolis and Gibbs sampling move by slow random walks, and several tricks (gradients, biased updates, temperature, interacting populations) can cut this, while an information-theoretic view shows why a plain Metropolis chain gains at most about one bit per step.
- [[mackay-2003-information/ch31-ising]] — An Ising model (spins ±1 with neighbour couplings) can be studied by Gibbs/Metropolis Monte Carlo or exactly by a transfer matrix whose largest eigenvalue gives the free energy of a long thin strip, with the simulations showing growing energy fluctuations (rather than a heat-capacity peak alone) as the interesting hint of a phase transition.
- [[mackay-2003-information/ch32-exact]] — By running coupled Markov chains from further and further in the past with the same random numbers until they all coalesce, one gets, for suitable chains, exact samples from the equilibrium distribution (Propp–Wilson "coupling from the past").
- [[mackay-2003-information/ch33-variational]] — Approximate an intractable distribution P by a simpler Q(θ) chosen to minimize the variational free energy, which equals D_KL(Q‖P) plus a constant, so that F̃ is also a bound on the true free energy (or on minus the log evidence).
- [[mackay-2003-information/ch34-independent]] — Independent component analysis (ICA) is maximum-likelihood fitting of a noise-free linear latent variable model with independent, non-Gaussian sources, and a covariant (unit-independent, natural-gradient) update makes it simple and fast.
- [[mackay-2003-information/ch35-random]] — For someone truly ignorant of a quantity's units, beliefs about its first digit should not change under rescaling (they are uniform on a log scale), which gives Benford's law; and Bayesian inference, with priors that state one's real assumptions, can be applied to problems such as mutation rates and the direction of arrows.
- [[mackay-2003-information/ch36-decision]] — Choose the action with the highest expected utility; the remaining difficulties are that choosing the utility function may be quite hard and that expected utility can be hard to compute, especially when actions bring information.
- [[mackay-2003-information/ch37-bayesian]] — MacKay argues that sampling-theory tools (p-values, confidence levels) do not answer the question we care about and can depend on irrelevant facts, whereas Bayesian posteriors answer it directly.
- [[mackay-2003-information/ch39-single]] — A single sigmoid neuron, whose output can be viewed as a class probability, can be trained by gradient descent on an error function built from information contents (relative entropy), optionally with weight decay, to give a simple supervised classifier.
- [[mackay-2003-information/ch40-capacity]] — For large K, a binary threshold neuron with K weights can almost certainly memorize up to N = 2K random binary labels, but will almost certainly fail to memorize more; its capacity is two bits per weight.
- [[mackay-2003-information/ch41-learning]] — Minimizing a neural network's regularized error is finding the (locally) most probable weights under a Bayesian posterior, and predictions are better when averaged over the whole posterior than made with those weights alone.
- [[mackay-2003-information/ch42-hopfield]] — A fully connected network with symmetric weights and Hebbian (outer-product) learning has an energy-like Lyapunov function when its neurons are updated one at a time, so its dynamics settle into stable states that act as an associative memory, with a measurable capacity of about 0.138 I random patterns for I neurons.
- [[mackay-2003-information/ch43-boltzmann]] — A Boltzmann machine is a stochastic Hopfield network whose maximum-likelihood learning compares correlations measured on data ("waking") with correlations under its own model ("sleeping"); hidden units can induce higher-order correlations among visible units while the model keeps only pairwise weights.
- [[mackay-2003-information/ch44-supervised]] — Training a neural network by minimizing error plus weight decay can be given a Bayesian interpretation: the objective is a negative log posterior up to a constant, and the evidence can then be used to tune model complexity without a test set.
- [[mackay-2003-information/ch45-gaussian]] — A Gaussian process puts a prior directly on functions, so that any finite set of function values is jointly Gaussian and regression becomes matrix algebra with a covariance function.
- [[mackay-2003-information/ch46-deconvolution]] — Under Gaussian assumptions, the most probable deblurred image is a regularized linear filter of the data, which a minimum-square-error argument also gives; better image priors, such as positive-only ones, improve on it.
- [[mackay-2003-information/ch47-low]] — A block code whose parity-check matrix is sparse can be decoded well by passing probability messages along its graph (the sum–product algorithm), even though decoding LDPC codes is NP-complete.
- [[mackay-2003-information/ch48-convolutional]] — A convolutional code is a linear shift-register filter whose valid outputs form a trellis, and a turbo code joins such codes (often two) through permutations and decodes them by passing messages between their trellises.
- [[mackay-2003-information/ch49-repeat]] — A repetition code followed by a random permutation and a running mod-2 sum gives a very simple sparse-graph code that decodes well with the sum–product algorithm, and "generalized parity-check matrices" put many such codes in one notation.
- [[mackay-2003-information/ch50-digital]] — Digital fountain (LT) codes make an endless stream of random sparse XOR packets, so a receiver can rebuild a file of K packets from slightly more than K received packets, using a very cheap peeling decoder and no feedback.
- [[mackay-2003-information/ch51-appendices]] — The appendices give the book's notation and four toolkits: partition functions and phase transitions, Galois fields for linear codes, eigen-analysis of (transition) matrices with first- and second-order perturbation formulas, and a table of reference numbers.

## Big ideas across units
- **Entropy is the price of description.** Information content and entropy are defined in ch02. Ch04 shows that about NH bits describe N symbols, via the typical set. Ch05–ch07 turn this into symbol codes, stream codes and integer codes. Ch08 extends entropy to dependent variables, and ch17–ch18 reuse the counting logic for constrained channels and language.
- **A noisy channel has a capacity, and reliable communication is possible up to it.** The idea starts in ch01, is defined and sketched in ch09, and is proved by random coding in ch10. Ch11, ch13 and ch14 treat Gaussian channels, distance and linear codes. Ch15 gives multi-user variants, ch17 the capacity of constrained channels, and ch40 the capacity of a neuron.
- **Inference is Bayes' theorem applied honestly.** Ch02 and ch03 set out posterior, likelihood and evidence. Ch21 and ch24 compute them exactly, ch25–ch26 do so on graphs, and ch35–ch37 contrast the Bayesian view with sampling theory and apply it to decisions. Ch41 and ch44–ch46 apply it to learning.
- **Model comparison has a built-in Occam's razor.** The idea appears in ch03 and ch24 (the Occam factor in marginalizing μ), is developed in ch28 with Laplace's approximation and MDL, and is used in ch44–ch45, where the evidence sets regularization and hyperparameters.
- **Local message passing computes global answers.** Counting soldiers and paths in ch16 leads to trellis decoding in ch25 and factor graphs in ch26. The same sum–product and min–sum algorithms then decode LDPC, turbo, repeat–accumulate and fountain codes in ch47–ch50.
- **Practical codes close the gap to Shannon.** Ch11 notes that good practical codes are hard to find and that decoding is the difficulty. Ch13 and ch14 relate code distance and random linear codes to the limit. Sparse-graph codes in ch47–ch50 come very close to it.
- **When exact inference is too costly, approximate it.** Enumeration scales exponentially (ch21). The alternatives are Laplace's method (ch28), Monte Carlo (ch29–ch32, ch41), and variational methods (ch33, ch22, ch20). Ch30 views a Metropolis chain as a channel with limited information gain per step.
- **Neural networks are inference and communication problems.** Ch39–ch40 treat the single neuron as a classifier and as a channel. Ch41, ch44 and ch45 make weights and functions the object of a posterior. Ch42–ch43 link Hopfield networks and Boltzmann machines to spin systems and maximum likelihood (see also ch31).

## How to read it
- **Essential (core path):** ch01, ch02, ch04, ch05, ch06, ch08, ch09, ch10 for the information theory, then ch28 (evidence and Occam's razor) and ch33 (variational methods). These are the chapters on the catalog focus list, whose focus also includes ch03 only indirectly. Ch03's ideas are needed in ch28, so read ch03 too.
- **Dependencies stated in the material:**
  - ch04 needs ch02 (entropy, Gibbs' inequality).
  - ch05 builds on ch04.
  - ch06 needs ch05 and Laplace's rule from ch02–ch03.
  - ch08 needs ch02.
  - ch09 needs ch02, ch04 and ch08.
  - ch10 needs ch04, ch09 and the data processing inequality from ch08.
  - ch11 needs ch09 and ch10.
  - ch14 needs ch04 and ch13.
  - ch16 is needed for ch17 (trellis counting), ch25 and ch26.
  - ch25 needs ch16, ch26 builds on ch16, and ch47–ch49 build on the message-passing ideas of ch25 and ch26.
  - ch22 follows ch20 (soft K-means) and ch21.
  - ch24 needs ch23's distributions.
  - ch28 needs the Bayes machinery of ch03.
  - ch29 needs the typical set (ch04).
  - ch30 needs ch29.
  - ch32 needs ch29 and ch31.
  - ch33 needs ch20/22 (soft K-means) and the relative entropy of ch02.
  - ch40 needs ch39, ch41 needs ch39, and ch44 needs the neuron chapters.
  - ch42 needs ch39–ch40, and ch43 needs ch42.
- **Can be skipped on a first pass:** ch07, which the book calls an aside. Also ch12 (hashing) and ch15 (exercises), ch18–ch19 (applications), ch35–ch36 (side topics and decisions), ch46 (deconvolution), and ch51 (reference appendices). Among the Monte Carlo chapters, ch30–ch32 go beyond the basic methods of ch29. The code chapters ch13 and ch47–ch50 matter if you want practical coding, and are less so if you only want inference.
