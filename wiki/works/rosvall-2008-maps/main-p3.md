## Toy example (ours, not from the text)
Purpose: show how a "field name + percentage + numbered journal list" can be built. The meaning of the percentage is assumed here, because these pages do not define it.

Assume six journals A–F with these weights, which sum to 100: A = 30, B = 20, C = 10, D = 25, E = 10, F = 5. Suppose a grouping gives field X = {A, B, C}, field Y = {D, E} and field Z = {F}.

- Field X: 30 + 20 + 10 = 60, so 60/100 = 60%.
- Field Y: 25 + 10 = 35, so 35%.
- Field Z: 5, so 5%.

Check: 60 + 35 + 5 = 100.

Ordering fields by decreasing percentage gives 1 X (60%), 2 Y (35%), 3 Z (5%). The journals are then listed inside each field. This mirrors the layout seen on pdf 42–62.
